%% Chapter 1: background of the project, differences to the upstream template,
\chapter{BoyogalaElegantBook}
\begin{quotation}
  \textbf{\textcolor{red}{BoyogalaElegantBook is a slimmed-down and modernised fork of ElegantBook: a single font configuration, no redundant options, fewer dependencies, faster compilation and identical output on every platform.}}
\end{quotation}

BoyogalaElegantBook is based on \href{https://github.com/ElegantLaTeX/ElegantBook}{ElegantBook}, created by \href{https://github.com/EthanDeng}{Ethan Deng} and \href{https://github.com/Liam0205}{Liam Huang} and later maintained by \href{https://github.com/EthanDeng}{Ethan Deng}, \href{https://github.com/syvshc}{syvshc} and \href{https://github.com/sikouhjw}{sikouhjw}.  This fork changes the following:

\begin{itemize}
  \item \textbf{One single font configuration}: all Latin, Chinese and maths fonts are bundled in the \lstinline{fonts/} directory.  The \lstinline{math} and \lstinline{chinesefont} options are gone, and no system font is required any more.
  \item \textbf{XeLaTeX only}: every font is loaded through \lstinline{fontspec} and \lstinline{unicode-math}.
  \item \textbf{Fewer dependencies}: \lstinline{tikz}, \lstinline{mwe}, \lstinline{lipsum}, \lstinline{makecell} and \lstinline{hologo} are not loaded any more; the decorative symbols are taken from the maths font.
  \item \textbf{Bug fixes}: the undefined colour error of \lstinline{color=none} is fixed, and the language modes are reduced to Chinese (simplified and traditional) and English.
  \item \textbf{Licence friendly}: all bundled fonts are released under the SIL Open Font License 1.1.
\end{itemize}

This guide introduces the settings and the basic usage of the template.  Questions, suggestions and comments are welcome on GitHub: \href{https://github.com/boyogala/BoyogalaElegantBook/issues}{issues}.

\begin{itemize}
  \item This project: \href{https://github.com/boyogala/BoyogalaElegantBook}{https://github.com/boyogala/BoyogalaElegantBook}
  \item Upstream project: \href{https://github.com/ElegantLaTeX/ElegantBook}{ElegantBook}
  \item Contact: \mailto{boyogala@qq.com}
\end{itemize}

\section{Portable Version}
Download the whole project from GitHub and unpack it:

\begin{lstlisting}
BoyogalaElegantBook/
├── boyogalaelegantbook.cls   % the class file
├── boyogalaelegantbook-cn.tex % the Chinese manual
├── boyogalaelegantbook-en.tex % this manual
├── fonts/                     % the font files (must be kept)
└── figure/, image/            % cover and illustrations
\end{lstlisting}

Then compile it with XeLaTeX \textbf{from the project root directory}:

\begin{lstlisting}
xelatex boyogalaelegantbook-en.tex
% or
latexmk -xelatex boyogalaelegantbook-en.tex
\end{lstlisting}

The font path is relative (\lstinline{./fonts/}), so compiling from another directory will not find the fonts.


\section{Requirements}
The template is tested with \TeX~Live 2023 or later on Windows, Ubuntu and macOS.  It needs \lstinline{fontspec}, \lstinline{xeCJK}, \lstinline{ctex}, \lstinline{unicode-math}, \lstinline{tcolorbox}, \lstinline{titlesec}, \lstinline{fancyhdr}, \lstinline{tocloft} and \lstinline{biblatex}, all of which are part of a full \TeX~Live installation.

You can use cmd/terminal to update the tlmgr itself and all the packages, the commands are:
\begin{lstlisting}
tlmgr update --self
tlmgr update --all
\end{lstlisting}

To learn more, please refer to \href{https://tex.stackexchange.com/questions/55437/how-do-i-update-my-tex-distribution}{How do I update my \TeX\ distribution?}

%% 2.1 language modes: Simplified Chinese, Traditional Chinese and English
\section{Languages}
We defined one option named \lstinline{lang} which has three values: \lstinline{lang=en} (default), \lstinline{lang=cn} and \lstinline{lang=cht}. Different values will alter the captions of figure/table, abstract name, refname, etc. You can use this option as

\begin{lstlisting}
\documentclass[en]{boyogalaelegantbook} 
\documentclass[lang=en]{boyogalaelegantbook}
\end{lstlisting}

The template provides three language modes only: Simplified Chinese
(\lstinline{lang=cn}), Traditional Chinese (\lstinline{lang=cht}) and English
(\lstinline{lang=en}, the default).  The language mode changes the caption
prefixes (Figure, Table), the structural names (Contents, Bibliography, ...)
and the names of the theorem environments (Theorem, Definition, Lemma, ...).

\begin{lstlisting}
\documentclass[cht]{boyogalaelegantbook} % Traditional Chinese
\documentclass[lang=en]{boyogalaelegantbook}
\end{lstlisting}

\begin{remark}
Simplified and Traditional Chinese share the very same fonts, only the
structural names differ; therefore the traditional characters are typeset with
the shapes of the bundled Simplified Chinese font.  Use
\lstinline|\setCJKmainfont| in the preamble if you prefer the Taiwanese
glyph shapes.
\end{remark}

%% 2.6 theorem environments: fancy and simple, counters and custom theorems
\section{Introduction of Math Environments}
We defined two sets of theorem modes, \lstinline{simple} style and \lstinline{fancy} style (default). You may change to \lstinline{simple} mode by

\begin{lstlisting}
\documentclass[simple]{boyogalaelegantbook} %or
\documentclass[mode=simple]{boyogalaelegantbook}
\end{lstlisting}

In this template, we defined four different theorem class environments

\begin{itemize}
\item \textit{Theorem Environments}, including title and content, numbering corresponding to chapter. Three types depending on the format:
   \begin{itemize}
      \item \textcolor{main}{\textbf{definition}} environment, the color is  \textcolor{main}{main};
      \item \textcolor{second}{\textbf{theorem, lemma, corollary, axiom, postulate}} environment, the color is \textcolor{second} {second};
      \item \textcolor{third}{\textbf{proposition}} environment, the color is \textcolor{third}{third}.
   \end{itemize}
\item \textit{Example Environment}, including \textbf{example, exercise, problem} environment, auto numbering according to chapter.
\item \textit{Proof Environment}, including \textbf{proof, note} environment containing introductory symbol (\textbf{note} environment) or ending symbol (\textbf{proof} environment).
\item \textit{Conclusion Environment}, including \textbf{conclusion, assumption, property, remark and solution}\footnote{We also define an option \lstinline{result}, which can hide the \lstinline{solution} and \lstinline{proof} environments. You can switch between \lstinline{result=answer} and \lstinline{result=noanswer}.} environments, all of which begin with boldfaced words, with format consistent with normal paragraphs.
\end{itemize}

All of theorem environments have star versions: \textcolor{main}{\textbf{definition*}}, \textcolor{second}{\textbf{theorem*}}, \textcolor{second}{\textbf{lemma*}}, \textcolor{second}{\textbf{corollary*}}, \textcolor{second}{\textbf{axiom*}}, \textcolor{second}{\textbf{postulate*}}, \textcolor{third}{\textbf{proposition*}}. Environments with an asterisk are not numbered.

\subsection{Theorem Class Environments}

\subsubsection{\lstinline{fancy} mode}

In \lstinline{fancy} mode, the template uses the \lstinline{tcolorbox} package to customize the theorem class environments, it is slightly different from the normal theorem environments. The usage is as follows:
\begin{lstlisting}
  % name + label
  \begin{theorem}{theorem name}{label}
    The content of a theorem with name and label. 
    Use \ref{thm:label} to refer this theorem.
  \end{theorem}
  % no name + label
  \begin{theorem}{}{label no name}
    The content of a theorem without name.
    Use \ref{thm:label no name} to refer this theorem.
  \end{theorem}
  % name + no label
  \begin{theorem}{theorem name}{}
    The content of a theorem without label.
    Can't refer this theorem.
    The last {} can be removed.
  \end{theorem}
  % no name + no label
  \begin{theorem}{}{}
    The content of a theorem without name and label.
    Can't refer this theorem.
    Both of {} can be removed.
  \end{theorem}
  \end{lstlisting}

The first parameter \lstinline{theorem name} represents the name of the theorem. If the current theorem has no name, please use \lstinline|{||\cprotect\footnote{Unless this theorem has neither no label, you should not omit this \verb|{}|.}, and the second parameter \lstinline{label} represents the label used in cross-reference with \verb|\ref{thm:label}|. Note that cross-references must be prefixed with \lstinline{thm:}. 

Other theorem class environments with the same usage includes:

\begin{table}[htbp]
\centering
\caption{Theorem Class Environments}
  \begin{tabular}{llll}
  \toprule
  Environment & Label text & Prefix & Cross-reference \\
  \midrule
  definition & label & def   & \lstinline|\ref{def:label|| \\
  theorem & label & thm   & \lstinline|\ref{thm:label|| \\
  postulate & label & pos & \lstinline|\ref{pos:label|| \\
  axiom & label & axi & \lstinline|\ref{axi:label||\\
  lemma & label & lem   & \lstinline|\ref{lem:label|| \\
  corrlary & label & cor   & \lstinline|\ref{cor:label|| \\
  proposition & label & pro   & \lstinline|\ref{pro:label|| \\
  \bottomrule
  \end{tabular}%
\label{tab:theorem-class}%
\end{table}%

From version 4.1, you can write your theorem environments as follows:
\begin{lstlisting}
\begin{theorem}[theorem name]\label{thm:theorem-label}
  The content of theorem.
\end{theorem}
% or
\begin{theorem}\label{thm:theorem-without-name}
  The content of theorem.
\end{theorem}
\end{lstlisting}

In this case, cross-reference don't have to be prefixed, i.e. the parameter of \lstinline{\ref} is the same as that of \lstinline{\label}.
 
\subsubsection{\lstinline{simple} mode}

In \lstinline{simple} mode, the template uses the \lstinline{amsthm} package to customize the theorem class environments. The usage is as follows:

\begin{lstlisting}
\begin{theorem}[theorem name]\label{thm:theorem-label}
  The content of theorem.
\end{theorem}
% or 
\begin{theorem}\label{thm:theorem-without-name}
  The content of theorem without name.
\end{theorem}
\end{lstlisting}

\subsection{Counter for Theorem Environments}

You can use \lstinline{thmcnt} option to control the theorem counter/number display style for the theorem environments, the acceptable options are \lstinline{chapter} (default) and \lstinline{section}:

\begin{lstlisting}
\documentclass[section]{boyogalaelegantbook} % turn the Theorem 4.1 to Theorem 4.1.1 
\documentclass[thmcnt=section]{boyogalaelegantbook}
\end{lstlisting}


\subsection{Other Customized Environments}
The other three math environments can be called directly since there are no additional option for them, e.g. \lstinline{example}:
\begin{lstlisting}
\begin{example}
This is the content of example environment.
\end{example}
\end{lstlisting}

The effect is as follows:

\begin{example}
This is the content of example environment.
\end{example}

These are all similar environments with slight differences lies in:

\begin{itemize}
   \item Example, exercise, problem environments number within chapter;
   \item Note begins with introductory symbol and proof ends with ending symbol;
   \item Conclusion and other environments are normal paragraph environments with boldfaced introductory words.
\end{itemize}

\subsection{Engine}
The template supports \textbf{XeLaTeX only}.  Every font is loaded through \lstinline{fontspec} and \lstinline{unicode-math}; compiling with another engine raises an error that asks for XeLaTeX.

\begin{lstlisting}
xelatex boyogalaelegantbook-en.tex
% or
latexmk -xelatex boyogalaelegantbook-en.tex
\end{lstlisting}

\subsection{Chinese fonts}
The four Chinese roles of a traditional book are kept: Song (body text), Hei (bold and headings), Kai (theorem bodies and italics) and Fangsong (proof bodies).  They are available as \lstinline|\songti|, \lstinline|\heiti|, \lstinline|\kaishu| and \lstinline|\fangsong| in the \lstinline|lang=cn| and \lstinline|lang=cht| modes.

\subsection{Maths font}
Maths is set with STIX Two Math through \lstinline{unicode-math}, which provides the complete AMS symbol set together with the blackletter, fraktur, calligraphic and script alphabets.  As the \lstinline{bm} package is not compatible with \lstinline{unicode-math|, it is not loaded any more; \lstinline|\bm| is defined as \lstinline{unicode-math}'s \lstinline|\symbf| instead, so the usage is unchanged.

\subsection{Customising the fonts}
The fonts may be replaced in the preamble, for instance with a locally installed family:

\begin{lstlisting}
\setmainfont{TeX Gyre Termes}[
  Extension = .otf,
  UprightFont = *-regular,
  BoldFont = *-bold,
  ItalicFont = *-italic,
  BoldItalicFont = *-bolditalic]
\end{lstlisting}

Such a definition overrides the default set-up of the class; to change a single shape only, use the \lstinline{ItalicFont}, \lstinline{BoldFont} and friends options of \lstinline{fontspec} (see \lstinline{texdoc fontspec}).

%% 2.8 bibliography: biblatex, its backends and styles
\section{Bibliography}

This template uses biblatex to generate the bibliography, the default citestyle and bibliography style are both \lstinline{numeric}. Let's take a glance at the citation effect. ~\cite{en1} use data from a major peer-to-peer lending \cite{en3} marketplace in China to study whether female and male investors evaluate loan performance differently \parencite{en2}. 

If you want to use biblatex, you must create a file named \lstinline{reference.bib}, add bib items (from Google Scholar, Mendeley, EndNote, and etc.) to \lstinline{reference.bib} file, then cite the bibkey in the \lstinline{tex} file. The biber will automatically generate the bibliography for the reference you cited.

In order to get the editors' auto-completion working, you need to add following code in your preamble:

\begin{lstlisting}
  \addbibresource[location=local]{reference.bib}
\end{lstlisting}

Then include the print commands where you want to print the bibliography:
\begin{lstlisting}
  \printbibliography[heading=bibintoc, title=\ebibname]
\end{lstlisting}

\begin{proposition}[Size of Left Coset]
Let $H$ be a finite subgroup of a group $G$.  Then each left coset of $H$ in $G$ has the same number of elements as $H$.
\end{proposition}

\begin{proof}
  Let $z$ be some element of $xH \cap yH$. Then $z = xa$ for some $a \in H$, and $z = yb$ for some $b \in H$. If $h$ is any element of $H$ then $ah \in H$ and $a^{-1}h \in H$, since $H$ is a subgroup of $G$. But $zh = x(ah)$ and $xh = z(a^{-1}h)$ for all $h \in H$. Therefore $zH \subset xH$ and $xH \subset zH$, and thus $xH = zH$.  Similarly $yH = zH$, and thus $xH = yH$, as required. 
\end{proof}

\textbf{Summation Operator} is an abbreviation used to express the summation of numbers, it plays an important role in statistics and econometrics analysis. If $\{x_i: i=1, 2, \ldots, n\}$ is a sequence of $n$ numbers, the summation of the $n$ numbers is:

\begin{equation}
\sum_{i=1}^n x_i \equiv x_1 + x_2 +\cdots + x_n
